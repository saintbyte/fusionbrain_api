# fusionbrain_api
fusionbrain.ai , Kandinsky
Библиотек для доступа к API https://fusionbrain.ai .

### Документация
Вот тут: https://pkg.go.dev/github.com/saintbyte/fusionbrain_api и смотрите примеры.

### Настройка
Надо получить API Key и засунуть его в переменную среды FUSIONBRAIN_API_KEY или
выставить свойство SecretKey обьекту класса Fusionbrain
